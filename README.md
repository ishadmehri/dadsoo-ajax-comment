# Elin Agax Comment

افزونهٔ سبک وردپرس برای نمایش و مدیریت فرم و فهرست دیدگاه‌های سفارشی با رابط کاربری AJAX.

## قابلیت‌ها

- ارسال دیدگاه بدون بارگذاری مجدد صفحه
- نمایش تدریجی دیدگاه‌های تأییدشده
- پاسخ تو در تو به دیدگاه‌ها
- لایک و دیسلایک با امکان تغییر یا لغو رأی
- استفاده از آواتار وردپرس و نمایش تاریخ دیدگاه
- بررسی nonce در درخواست‌های AJAX

## نیازمندی‌ها

- WordPress 5.8 یا جدیدتر
- PHP 7.4 یا جدیدتر
- jQuery (همراه هستهٔ وردپرس)

## نصب

1. پوشهٔ افزونه را در `wp-content/plugins/elin-agax-comment` قرار دهید.
2. افزونه را از بخش «افزونه‌ها» در پیشخوان وردپرس فعال کنید.
3. در برگه یا قالب موردنظر از شورت‌کدهای زیر استفاده کنید:

   ```text
   [elin-agax-comment-form]
   [elin-agax-comments]
   [elin-agax-comments items="10"]
   ```

دیدگاه‌ها و پاسخ‌های جدید با وضعیت «در انتظار تأیید» ثبت می‌شوند و از بخش دیدگاه‌های وردپرس قابل مدیریت هستند.

## توسعه

فایل اصلی افزونه `elin-agax-comment.php` است. استایل‌ها و رفتار سمت مرورگر به‌ترتیب در `assets/css/style.css` و `assets/js/script.js` قرار دارند. توسعه و نگهداری پروژه توسط [Elinweb](https://elinweb.ir) انجام می‌شود.

## انتشار

مجوز انتشار هنوز تعیین نشده است. پیش از عمومی‌کردن مخزن، یک مجوز مناسب انتخاب و فایل `LICENSE` را اضافه کنید.
